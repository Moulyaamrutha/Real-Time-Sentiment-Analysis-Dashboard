## 📌 Project Overview

This project implements a **real-time sentiment analysis system** using a fine-tuned **BERT model** to classify text data into positive, negative, or neutral sentiments.

The system processes user input or dataset streams and visualizes results through an interactive dashboard, enabling real-time monitoring of public opinion.

---

## 🎯 Business Use Case

* Monitor customer sentiment in real time
* Analyze social media trends
* Detect negative feedback spikes
* Support data-driven decision-making

---

## 🧠 Model Details

* Pretrained Transformer: **BERT**
* Fine-tuned on Twitter sentiment dataset
* Handles contextual understanding of text
* Stored using `.safetensors` for efficiency
